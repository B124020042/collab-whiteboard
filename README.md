# 協作白板 Collaborative Whiteboard

企業資訊通訊期末專案：多人透過網路在同一張畫布上即時畫圖。
只使用 Python 標準函式庫 (`asyncio`、`socket`、`threading`、`tkinter`)，不需安裝任何套件。

## 功能

- **即時同步**：任何人畫的線會立刻出現在同房間所有人的畫面上
- **畫筆工具**：8 色調色盤＋自訂顏色、粗細調整、橡皮擦
- **文字框**：點畫布輸入文字，可選顏色與字級；點一下 (文字工具) 或雙擊 (選取工具) 可修改
- **選取**：點選、Shift 加選、拖曳框選、全選；選取後可拖曳移動
- **縮放**：拉選取框的 8 個控制點改變大小 (四角等比例、按住 Shift 自由縮放；四邊只拉單一方向)，筆跡粗細與文字字級會一起調整
- **右鍵選單**：在物件上按右鍵可複製、剪下、刪除、編輯文字；在空白處按右鍵可把內容貼在該位置
- **複製 / 剪下 / 貼上 / 刪除**：使用系統剪貼簿，可在不同視窗、甚至不同人之間貼上；從其他程式複製的純文字貼上後會變成文字框
- **復原 (Ctrl+Z)**：移除「自己」最後新增的物件 (筆跡、文字、貼上的內容)，不會動到別人的
- **清除畫布**
- **儲存 / 開啟 (Ctrl+S / Ctrl+O)**：存成 `.json` 白板檔，之後可再開啟，載入的內容會同步給房間內所有人 (可選擇先清除或疊加)；也可另存 `.ps` 圖檔 (僅圖片，無法再開啟)
- **他人游標**：即時顯示其他人的滑鼠位置與暱稱 (每人固定顏色)
- **多房間**：`--room` 指定房間，各房間畫布互相獨立
- **線上名單**、加入 / 離開通知、暱稱重複自動加編號
- **後加入者自動補齊畫面**：伺服器保存筆跡，新連線會收到完整重播
- **斷線自動重連**：網路恢復後自動重新連線並同步到最新畫面
- **一鍵啟動 / 自動探索** (`start.py`)：自動找到區網裡已經開著的伺服器並連線，找不到才自己開一個
- **Demo 機器人** (`bot.py`)：自動畫玫瑰線 / 螺旋，單人也能展示多人協作

## 執行方式

需要 Python 3.8 以上。tkinter 通常已內建；若出現 `No module named 'tkinter'`：
Ubuntu/Debian 執行 `sudo apt install python3-tk`，macOS (Homebrew) 執行 `brew install python-tk`。

### 最簡單：一鍵啟動 (推薦)

每台電腦都執行同一個指令就好，不用查 IP：

```bash
python3 start.py                       # 或 python3 start.py --name amy --room design
python3 start.py --check               # 只看找到哪些伺服器，不開白板
```

第一台會發現區網裡沒有伺服器，自動在本機開一個；之後的電腦會自動找到它並連上。
開伺服器的那台關閉白板時，若還有人在用，伺服器會繼續執行，等所有人離開才關閉 (Ctrl+C 可強制關閉)。伺服器的紀錄寫在 `server.log`。

> 找不到別台的伺服器時：確認在同一個網路、伺服器那台防火牆允許 Python (TCP 9100、UDP 9101)。學校 / 公司 Wi-Fi 常會擋住裝置互連，最快的解法是大家連同一支手機熱點。

### 手動啟動

```bash
# 1. 啟動伺服器 (預設 port 9100)
python3 server.py

# 2. 開多個客戶端 (可以在不同電腦，用 --host 指定伺服器 IP)
python3 client.py --name alice
python3 client.py --name bob --host 192.168.1.10
python3 client.py --name carol --room design     # 另一個房間

# 3. (選用) 讓機器人一起畫
python3 bot.py --name robot --count 5

# 4. 自動化測試 (不需要螢幕)
python3 test_server.py     # 伺服器與通訊協定
python3 test_client.py     # 客戶端邏輯
python3 test_start.py      # 自動探索 / 一鍵啟動
```

### 操作說明

| 工具 / 動作 | 操作 |
|------|------|
| 畫筆 `P`、橡皮擦 `E` | 按住左鍵拖曳 |
| 文字 `T` | 點畫布開始輸入；`Enter` 完成、`Shift+Enter` 換行、`Esc` 取消；點既有文字可修改，清空內容即刪除 |
| 選取 `V` | 點選物件；`Shift`+點擊加選 / 取消；從空白處拖曳框選；拖曳已選物件可移動；雙擊文字可修改 |
| 縮放 | 拖曳選取框的控制點：四角等比例 (按住 `Shift` 自由縮放)，上下左右四邊只改高或寬 |
| 右鍵選單 | 複製、剪下、貼上 (貼在按右鍵的位置)、刪除、編輯文字、全選、復原；在物件上按右鍵會自動選取它 (macOS 也可用 Control+點擊) |
| 複製 / 剪下 / 貼上 | 右鍵選單，或 `Ctrl+C` / `Ctrl+X` / `Ctrl+V` (macOS 用 `Cmd`)；用快捷鍵貼上會往右下偏移 |
| 刪除、全選、取消選取 | 右鍵選單，或 `Delete` / `Backspace`、`Ctrl+A`、`Esc` |
| 復原、開啟、儲存 | `Ctrl+Z`、`Ctrl+O`、`Ctrl+S` |

正在輸入文字時，快捷鍵會交給文字框本身處理 (例如 `Ctrl+C` 是複製文字框裡的字)。

跨電腦手動連線時要用 `--host` 指定伺服器 IP (伺服器啟動時會印出)，且伺服器那台的防火牆要開放 TCP 9100。

## 架構

```
┌──────────── client.py ────────────┐            ┌──────── server.py ────────┐
│ 主執行緒 (tkinter)                 │            │ asyncio 事件迴圈 (單執行緒) │
│  滑鼠事件 → 本機先畫 → 累積點座標   │──TCP──────▶│  rooms: {房間: Room}       │
│  每 30ms 批次送出 draw             │  JSON      │   ├ users   線上使用者      │
│  每 15ms 從 queue 取訊息更新畫面 ◀─┐│  lines     │   └ strokes 筆跡 (有序)     │
│ 網路執行緒 (Net)                   ││◀───────────│  轉發給同房間其他人         │
│  連線 / 自動重連 / 讀取 → queue ───┘│            │  新加入者 → 完整重播        │
└────────────────────────────────────┘            └───────────────────────────┘
```

### 通訊協定

TCP 之上自訂應用層協定：每則訊息是一行 UTF-8 JSON，以 `\n` 分隔，解決 TCP 位元組串流沒有訊息邊界 (黏包) 的問題。完整定義見 `protocol.py`。

| 方向 | type | 內容 |
|------|------|------|
| C→S | `hello` | 暱稱、房間 |
| C→S | `draw` | 筆跡 id、顏色、粗細、一批點座標 |
| C→S | `text` | 新增 / 修改文字框 (位置、內容、顏色、字級) |
| C→S | `move` / `delete` | 移動 / 刪除多個物件 |
| C→S | `cursor` / `undo` / `clear` | 游標位置 / 復原 / 清除 |
| S→C | `welcome` | 最終暱稱、線上名單、目前所有筆跡 |
| S→C | `draw` / `text` / `move` / `cursor` | 轉發他人的筆跡、文字、移動、游標 |
| S→C | `remove` / `clear` | 移除某筆 / 清空 |
| S→C | `user_join` / `user_leave` | 使用者進出 |

### 設計重點

1. **比例座標**：座標一律用 0~1 傳送，各客戶端依自己的視窗大小換算，視窗縮放後也會重繪。
2. **批次傳送**：滑鼠移動事件每秒可達上百次。先在本機立即畫出 (零延遲手感)，點座標累積後每 30ms 送一批，封包數大幅下降。每批會多帶前一批的最後一點，讓線段連續。
3. **游標節流**：游標位置最多每 50ms 送一次；它是「最新值才重要」的資料，丟掉舊值不影響結果 (這類資料也適合改用 UDP)。
4. **GUI 執行緒安全**：tkinter 只能在主執行緒操作，所以網路執行緒只把訊息放進 `queue.Queue`，主執行緒用 `root.after()` 定時取出處理。
5. **一致性**：伺服器接收順序就是最終順序；客戶端每次 (重新) 連線都以伺服器的 `welcome` 完整狀態為準。
6. **物件模型**：畫布上的筆跡與文字都是「物件」，共用同一組 id。任何人都可移動、刪除、編輯文字 (協作白板的常見做法)，但只能接續自己的筆跡、復原自己新增的物件。
7. **移動同步**：拖曳時只在本機移動畫面，放開滑鼠才送出一次 `move` (位移量)，大幅減少流量。位移量的邊界限制 (不能移出畫布) 寫在 `protocol.py`，伺服器與客戶端用同一個函式計算，結果保證一致。
8. **縮放同步**：送出的是「基準點 + 倍率」而非每個點的新座標，封包很小。拖曳中每次都從按下時的原始狀態重新計算 (誤差不累積)，放開才送出；倍率限制 (不翻轉、不超出畫布) 與座標取 4 位小數都由 `protocol.py` 的共用函式處理，所以每台電腦的結果完全一致。
9. **剪貼簿**：複製時把物件以存檔格式 (JSON) 放進系統剪貼簿，所以能貼到另一個視窗；貼上時先判斷是否為白板資料，否則當成純文字建立文字框。
10. **存檔格式**：`.json` 存的是筆跡資料 (顏色、粗細、比例座標)，而不是像素，所以檔案小、縮放不失真，而且能重新載入並同步給所有人。載入時長筆跡會切成每段 ≤500 點送出 (段與段共用接點)；選「先清除再載入」時，客戶端會等伺服器廣播的 `clear` 回來後才開始送，避免剛載入的筆跡被清掉。
11. **自動探索**：`start.py` 依序嘗試 ① 本機 ② UDP 廣播 (`COLLAB_WHITEBOARD_DISCOVER` → UDP 9101，伺服器回傳人數與房間) ③ 平行 TCP 掃描同一個 /24 網段並送 `ping` 確認對方真的是白板伺服器 (廣播被擋時的備案)。找到多台時選人最多的、再比 IP，讓每台電腦選到同一台。都找不到時先隨機等一下再找一次，降低兩台同時啟動各開一個伺服器的機率。
12. **權限與防呆**：只能接續 / 復原自己的筆跡；伺服器檢查顏色格式、粗細範圍、座標範圍，壞掉的 JSON 直接忽略，不會讓伺服器崩潰。每房間最多保存 5000 筆。

## 測試

**`test_client.py`**：用一個簡化的假 tkinter 取代真正的視窗，讓兩個客戶端透過真的伺服器協作，驗證畫筆同步、文字框新增 / 修改 / 取消 / 清空刪除、點選 / 加選 / 框選 / 全選、拖曳移動與邊界限制、等比例 / 自由 / 單邊縮放與倍率限制、複製 / 剪下 / 貼上 (含跨視窗與純文字)、右鍵選單 (自動選取、選項啟用狀態、貼在指定位置)、打字時快捷鍵不誤觸、別人刪除正在編輯的文字、存檔與開啟。

**`test_server.py`**：啟動伺服器，用多個原始 socket 客戶端驗證文字 / 移動 / 刪除的權限與邊界，以及：
筆跡同步、不回送給自己、後加入者重播、復原只影響自己、房間隔離、游標座標限制、清除畫布、暱稱重複處理、離線通知、惡意或錯誤輸入、機器人壓力測試、存檔→讀檔→同步的完整流程、存檔格式驗證與長筆跡分段。

## 可延伸方向

- TLS 加密 (`ssl` 模組包裝 socket)
- 形狀工具 (矩形、圓形、箭頭)、改變已選物件的顏色、側邊聊天室
- 筆跡存入 SQLite，伺服器重啟後畫布仍在
- 用 WebSocket 做網頁版客戶端
